# Phase 37 — Mobile Add Items Stay On Menu

Mobile POS workflow fix. On phones/tablets, tapping an item or deal keeps the cashier on the menu screen. The bill drawer opens only when the cashier taps Bill/Open Bill/Pay. This improves rush-hour speed and prevents repeated close/reopen actions while adding multiple items.

## Fixed
- Removed automatic bill drawer opening after add item on mobile.
- Removed automatic bill drawer opening after add deal on mobile.
- Bill FAB total still updates instantly.
- Pay/Open Bill quick action still updates instantly.
- Desktop behavior remains unchanged.
